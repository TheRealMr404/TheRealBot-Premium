# نصب سرویس «پریمیوم و استارز خودکار»

روی سرور (با SSH) فقط همین یک دستور را اجرا کنید؛ مسیر ربات و نام دیتابیس خودکار پیدا می‌شوند:

```bash
sudo bash /var/www/html/mirzaprobotconfig/services/fragment-signer/install-service.sh
```

این دستور خودش Node.js، ماژول‌های sqlite/curl برای همه‌ی نسخه‌های PHP، سرویس systemd، cron سفارش‌ها و توکن را می‌سازد/تعمیر می‌کند و در پایان سلامت سرویس را چک می‌کند.
اجرای دوباره‌ی آن امن است (توکن و پورت قبلی حفظ می‌شوند). اگر ربات «سرویس امضا قطع» نشان داد، همین دستور را دوباره بزنید.

## راه‌اندازی در ربات
۱. پنل مدیریت ← خدمات مجازی ← **💎 پریمیوم و استارز خودکار ⭐** (اولین دکمه)
۲. کلید کیف پول (۲۴ کلمه) را ثبت کنید ← نسخه‌ی کیف پول را انتخاب کنید.
۳. «ورود خودکار Fragment» و «بررسی اتصال» را بزنید.
۴. پکیج‌ها را اضافه کنید، ابتدا در حالت آزمایشی تست کنید، سپس حالت را «واقعی» و فروش را «روشن» کنید.

## یافتن توکن (فقط در صورت نیاز)
```bash
sudo grep SIGNER_TOKEN /etc/mirza/fragment-signer-*.env
```
